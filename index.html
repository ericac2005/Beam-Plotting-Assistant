1. Define the Structural System

Supports

Intermediate Supports

Add intermediate supports between A and B. Choose Pin, Roller, or Hinge and enter each support location measured from the physical left end of the beam.

Overhangs are measured beyond the end supports. The drawing and determinacy check include them. The detailed solver can calculate a statically determinate pin/hinge-at-A and roller-at-B beam with left and/or right overhangs when no intermediate supports are present; continuous multi-support beams remain analysis-limited.

Planar Rigid Frame Geometry

Build the frame from vertical columns and rigid beam segments. You can model either a multi-column portal frame or a single-column frame/cantilever. Column positions are measured from the left reference line; adjacent column tops are connected automatically.

Columns

Internal Hinges / Moment Releases

Add a moment release at a beam or column location. A released member end carries no bending moment at that hinge. Beam hinges are located by global x; column hinges are located by the selected column and y-height.

Each column has a base support. Pin, Roller, and Fixed bases are available. In single-column mode, choose the condition at the far beam end: Free, Roller, Pin, or Fixed. The single-column frame solver uses a 2D rigid-frame stiffness model, so base reactions and member N/V/M are calculated for the selected end support.

Structural Count

2. Loads

Column Distributed Loads

For frame analysis, use this section to apply a distributed load directly along a selected column. Set the load intensity, the start/end height, and the global direction. The load is included in the frame stiffness solution and in the column N/V/M diagrams.

3. Verify Your Input

The structural drawing updates from your inputs before the analysis is performed. Use it to confirm that the problem has been entered correctly.

Review the drawing before continuing.
